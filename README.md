# Patagonia · generador de paisajes

Seeded hex-tile Patagonia landscapes with a tilt-shift miniature look (three.js, WebGPU).

Live: https://franpiaggio.github.io/patagonia-hex/

- Round button (or Space): next landscape
- Scroll / pinch: zoom · drag or sideways swipe: orbit
- `F` or `?full`: full-bleed mode · `A` or `?auto`: autoplay
- Quality adapts to the device; `?quality=low|medium|high` forces a tier

This repository holds only the static build.

## Versions

Each closed milestone stays frozen at its own path; the root always shows the latest.

- [`demo-01.3`](https://franpiaggio.github.io/patagonia-hex/demo-01.3/): standalone homesteads, sealed tile seams, hidden `?debug` panel (Tweakpane)
